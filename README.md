**Draconic Altar Calculator**  

This is a **Draconic Altar Simulator**, designed to estimate potential profits from sacrificing different types of fragments in Hypixel Skyblock.  

### Features  
- Fetches **Bazaar prices** from the Hypixel API.    
- Simulates **multiple iterations** to provide accurate profit estimations.  
- Calculates potential **drops & profits** from using the altar.  
- Provides a **GUI** with Tkinter.  

### Installation  
1. Clone the repository:  
   ```bash
   git clone https://github.com/Cametolose/Hypixel-Skyblock-Draconic-Altar-Calculator.git
   cd altar_calculator
   ```  
2. Install dependencies:  
   ```bash
   pip install -r requirements.txt
   ```  
3. Run the script:  
   ```bash
   python altar_calculator.py
   ```
